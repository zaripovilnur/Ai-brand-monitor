# Мониторинг бренда в ответах ИИ

Внутренний инструмент маркетинговой команды. Работает локально.

## Запуск

1. Установить зависимости — один раз:

   ```
   npm install
   ```

2. Создать файл `.env` из образца и вписать ключ AITunnel:

   ```
   cp .env.example .env
   ```

   Затем открыть `.env` и подставить свой ключ в строку `AITUNNEL_API_KEY=`.
   Файл `.env` не попадает в git и не уходит в браузер.

3. Запустить:

   ```
   npm run dev
   ```

   Поднимаются обе части сразу: бэкенд на `http://localhost:8787`,
   интерфейс на `http://localhost:5173`.

## Где что лежит

- `server/` — бэкенд (Express), все обращения к моделям идут отсюда
- `src/` — интерфейс (React + Vite)
- `prototype/` — утверждённый прототип интерфейса
- `data/app.db` — база SQLite, создаётся автоматически при первом запуске

## Запуск на сервере

Программа рассчитана на работу внутри команды: один сервер, доступ по паролю.

### Что понадобится

Сервер с Ubuntu 24.04 LTS, 2 ядра, 2 ГБ оперативной памяти, 20 ГБ диска.
Меньше тоже работает, но сборка фронтенда требует около 512 МБ памяти.

### Порядок установки

1. Поставить Node.js 22 и nginx.
2. Завести пользователя `monitor` и положить проект в `/opt/ai-brand-monitor`.
3. Установить зависимости и собрать фронтенд:

   ```
   npm install
   npm run build
   ```

4. Создать `.env` с ключом AITunnel (см. `.env.example`).
5. Настроить автозапуск — файл `deploy/ai-brand-monitor.service`, инструкция внутри.
6. Настроить nginx с паролем — файл `deploy/nginx.conf`, инструкция внутри.

Программа слушает только `127.0.0.1:8787`. Наружу её пускает nginx, который
и спрашивает пароль. Открытого доступа к сервису быть не должно: авторизации
внутри программы нет, а кнопка «Запустить прогон» тратит деньги с баланса шлюза.

### Пока нет домена

Бесплатный сертификат HTTPS выдаётся только на доменное имя, на IP-адрес его
не получить. До покупки домена закройте доступ к серверу по IP-адресам офиса
средствами файрвола — иначе пароль пойдёт по сети открытым текстом.

Когда домен появится:

```
apt install certbot python3-certbot-nginx
certbot --nginx -d монитор.ваш-домен.ру
```

### Резервные копии

Копировать нужно два файла: `data/app.db` (все прогоны и ответы) и `.env`
(ключ). Остальное восстанавливается из git.

### Обновление

```
git pull && npm install && npm run build && systemctl restart ai-brand-monitor
```

Прогон, оборванный перезапуском, продолжится сам — уже полученные ответы
не запрашиваются заново и второй раз не оплачиваются.
