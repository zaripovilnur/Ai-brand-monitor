# Мониторинг бренда в ответах ИИ

Внутренний инструмент маркетинговой команды. Работает локально.

## Запуск

1. Установить зависимости — один раз:

   ```
   npm install
   ```

2. Создать файл `.env` из образца и вписать ключ AITunnel:

   ```
   cp .env.example .env
   ```

   Затем открыть `.env` и подставить свой ключ в строку `AITUNNEL_API_KEY=`.
   Файл `.env` не попадает в git и не уходит в браузер.

3. Запустить:

   ```
   npm run dev
   ```

   Поднимаются обе части сразу: бэкенд на `http://localhost:8787`,
   интерфейс на `http://localhost:5173`.

## Где что лежит

- `server/` — бэкенд (Express), все обращения к моделям идут отсюда
- `src/` — интерфейс (React + Vite)
- `prototype/` — утверждённый прототип интерфейса
- `data/app.db` — база SQLite, создаётся автоматически при первом запуске
